# Plano de desenvolvimento

## Fase 1 — Fundamentos

- Configurar MongoDB com Docker Compose.
- Criar API Express com conexão Mongoose.
- Implementar CRUD de estampas.
- Definir validações e modelo de dados.

## Fase 2 — Interface

- Criar formulário de nova estampa e edição.
- Criar upload local de imagem com Multer.
- Implementar busca, filtro por status, técnica e coleção.
- Adicionar estados de carregamento, vazio e erro.

## Fase 3 — Experiência visual

- Consolidar tokens de cor, tipografia e espaçamento.
- Usar Motion para microinterações e transições.
- Usar GSAP para entrada da identidade visual e cenas de destaque.
- Revisar responsividade e acessibilidade.

## Fase 4 — Entrega

- Testar API e fluxo completo no Linux.
- Documentar comandos e endpoints.
- Subir o repositório público no GitHub.
- Preparar apresentação da arquitetura para a disciplina.
